# Backend

보건소 스마트 예약·대기 및 혼잡도 분석 시스템의 백엔드 프로젝트입니다.

## 예정 기술

- 전자정부프레임워크 기반 Spring Boot
- Java 17
- PostgreSQL
- JPA
- Spring Security
- Access Token / Refresh Token
- Swagger/OpenAPI

## 예정 패키지

```text
com.example.healthcenter
 ├─ common
 ├─ member
 ├─ office
 ├─ reservation
 ├─ visit
 ├─ queue
 └─ dashboard
```

## 현재 상태

아직 백엔드 프로젝트 생성 전입니다.
