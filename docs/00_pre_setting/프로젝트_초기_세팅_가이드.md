# 프로젝트 초기 세팅 가이드

## 1. 현재 상태

현재 상태는 다음과 같다.

| 항목 | 상태 |
|---|---|
| 기획 문서 | 작성 완료 |
| 설계 문서 ZIP | 작성 완료 |
| GitHub Repository | 아직 없음 |
| 로컬 프로젝트 폴더 | 아직 없음 |
| docs 폴더 | 아직 없음 |
| backend 폴더 | 아직 없음 |
| frontend 폴더 | 아직 없음 |
| 패키지 구조 | 아직 생성 전 |
| 코드 구현 | 아직 시작 전 |

따라서 지금은 코드를 작성하기 전에 **레포지토리 구조와 문서 배치부터 정리**해야 한다.

---

## 2. 가장 먼저 해야 할 일

첫 목표는 다음이다.

```text
GitHub Repository 생성
→ 로컬에 Clone
→ docs 폴더 생성
→ 설계 문서 배치
→ 루트 README 작성
→ .gitignore 작성
→ .editorconfig 작성
→ backend/frontend 빈 폴더 생성
→ 첫 문서 커밋 준비
```

아직 Java 패키지나 React 프로젝트는 만들지 않는다.  
먼저 저장소의 뼈대를 안정적으로 만든다.

## 5. GitHub Desktop 기준 시작 순서

### 5.1 GitHub에서 Repository 생성

1. GitHub 접속
2. New Repository 클릭
3. Repository name 입력

```text
health-center-smart-reservation
```

4. Public 또는 Private 선택
5. README 생성 여부는 선택 가능

추천:

```text
README는 생성하지 않고 빈 Repository로 만든다.
```

이유는 로컬에서 직접 README, docs, .gitignore를 정리한 뒤 첫 커밋을 넣는 것이 깔끔하다.

---

### 5.2 GitHub Desktop에서 Clone

1. GitHub Desktop 실행
2. File → Clone repository
3. 방금 만든 Repository 선택
4. 로컬 경로 선택

예시:

```text
C:\Dev\health-center-smart-reservation
```

5. Clone

## 12. docker-compose.yml 초안

아직 backend/frontend 프로젝트가 없으므로 처음에는 PostgreSQL만 실행하는 형태로 시작해도 된다.

```yaml
services:
  postgres:
    image: postgres:16
    container_name: health-center-postgres
    environment:
      POSTGRES_DB: health_center
      POSTGRES_USER: health
      POSTGRES_PASSWORD: health1234
    ports:
      - "5432:5432"
    volumes:
      - health-center-postgres-data:/var/lib/postgresql/data
    networks:
      - health-center-network

volumes:
  health-center-postgres-data:

networks:
  health-center-network:
    driver: bridge
```

나중에 backend, frontend 프로젝트가 생성되면 서비스를 추가한다.
