# 화면 설계서 및 v0 프롬프트

## 1. 화면 설계 원칙

| 원칙 | 설명 |
|---|---|
| 공공서비스 톤 | 신뢰감 있고 단정한 화면 |
| 접근성 | 큰 버튼, 명확한 상태 표시, 충분한 여백 |
| 업무 효율 | 직원 화면은 클릭 수를 최소화 |
| 정보 가독성 | 관리자 화면은 카드와 차트 중심 |
| 모바일 우선 | 일반 사용자 예약 화면은 모바일 사용성을 고려 |
| 상태 명확성 | 예약 상태, 대기 상태, 혼잡도를 색상과 텍스트로 명확히 표시 |

## 3. 화면 구조

### 사용자 화면

```text
┌─────────────────────────────────────┐
│ 보건소 스마트 예약                   │
├─────────────────────────────────────┤
│ 주요 안내 영역                       │
├─────────────────────────────────────┤
│ 업무 선택 / 예약 / 혼잡도 콘텐츠      │
├─────────────────────────────────────┤
│ 하단 안내 문구                       │
└─────────────────────────────────────┘
```

### 직원 화면

```text
┌────────────────────────────────────────────────────┐
│ 직원 업무 화면                                      │
├────────────────────────────────────────────────────┤
│ 오늘 예약자 수 | 현재 대기 인원 | 처리 완료 수      │
├────────────────────────────────────────────────────┤
│ 업무 필터 | 현장 접수 버튼 | 체크인 버튼            │
├────────────────────────────────────────────────────┤
│ 대기자 테이블                                      │
└────────────────────────────────────────────────────┘
```

### 관리자 대시보드

```text
┌────────────────────────────────────────────────────┐
│ 관리자 대시보드                                    │
├────────────────────────────────────────────────────┤
│ KPI 카드 4개                                       │
├──────────────────────────┬─────────────────────────┤
│ 시간대별 방문자 수 차트  │ 업무별 평균 대기시간     │
├──────────────────────────┴─────────────────────────┤
│ 예약/현장 비율 | 노쇼율 | 운영 개선 제안             │
└────────────────────────────────────────────────────┘
```

## 4. v0 프롬프트

### 4.1 로그인 화면

```text
보건소 스마트 예약·대기 시스템의 로그인 화면을 만들어주세요.
React, Tailwind CSS, shadcn/ui 스타일로 구성해주세요.

요구사항:
- 공공기관 서비스처럼 신뢰감 있고 단정한 디자인
- 상단 제목: 보건소 스마트 예약·대기 시스템
- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 링크
- 안내 문구: 보건소 방문 예약과 대기 현황을 확인할 수 있습니다.
- 모바일 화면에서도 보기 좋게 구성
```

### 4.2 사용자 예약 신청 화면

```text
보건소 스마트 예약 시스템의 사용자 예약 신청 화면을 만들어주세요.
React, Tailwind CSS, shadcn/ui 스타일로 구성해주세요.

화면 구성:
- 상단 제목: 보건소 방문 예약
- 업무 유형 선택 카드 3개:
  1. 예방접종
  2. 건강검진/검사
  3. 건강상담
- 날짜 선택 영역
- 예약 가능한 시간대 버튼 목록
- 선택한 예약 정보 요약 카드
- 예약 신청 버튼
- 하단 안내 문구:
  - 방문 전 신분증을 지참해주세요.
  - 예약은 방문 1시간 전까지 취소할 수 있습니다.

접근성을 고려하여 버튼은 크고 명확하게 만들어주세요.
```

### 4.3 직원 대기열 관리 화면

```text
보건소 직원용 대기열 관리 화면을 만들어주세요.
React, Tailwind CSS, shadcn/ui 스타일로 구성해주세요.

화면 구성:
- 상단 요약 카드: 현재 대기 인원, 호출 중, 처리 중, 보류
- 업무 유형 필터: 전체, 예방접종, 건강검진/검사, 건강상담
- 대기자 테이블:
  - 대기번호
  - 이름
  - 업무 유형
  - 접수 유형
  - 상태
  - 대기시간
- 각 행에 호출, 처리 시작, 완료, 보류 버튼
- 오른쪽 또는 상단에 현재 호출 중인 대기번호를 크게 표시

직원이 클릭 몇 번으로 상태를 변경할 수 있게 구성해주세요.
```

### 4.4 관리자 대시보드 화면

```text
보건소 관리자용 혼잡도 분석 대시보드를 만들어주세요.
React, Tailwind CSS, shadcn/ui, Recharts를 사용한 대시보드 스타일로 구성해주세요.

화면 구성:
- 상단 제목: 보건소 혼잡도 분석 대시보드
- 기간 선택 필터
- KPI 카드:
  - 오늘 방문자 수
  - 현재 대기 인원
  - 평균 대기시간
  - 노쇼율
- 시간대별 방문자 수 라인 차트
- 업무별 평균 대기시간 막대 차트
- 예약자/현장 방문자 비율 도넛 차트
- 혼잡 시간대 분석 카드
- 운영 개선 제안 카드

공공기관 관리자 화면처럼 신뢰감 있고 정보가 명확하게 보이도록 만들어주세요.
```

### 4.5 현장 접수 화면

```text
보건소 직원용 현장 접수 화면을 만들어주세요.
React, Tailwind CSS, shadcn/ui 스타일로 구성해주세요.

화면 구성:
- 상단 제목: 현장 접수
- 방문자 이름 입력
- 휴대폰 번호 입력
- 업무 유형 선택
- 접수 등록 버튼
- 접수 완료 시 대기번호를 크게 보여주는 카드
- 최근 현장 접수 목록

직원이 빠르게 입력할 수 있도록 단순한 폼으로 만들어주세요.
```
