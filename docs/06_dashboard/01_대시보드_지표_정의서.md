# 대시보드 지표 정의서

## 1. 대시보드 제공 대상

| 사용자 | 제공 범위 |
|---|---|
| 관리자 | 전체 통계와 분석 지표 |
| 직원 | 당일 대기 현황과 처리 현황 |
| 일반 사용자 | 현재 혼잡도와 예상 대기시간 |

## 2. 관리자 핵심 지표

| 지표 | 설명 | 계산 기준 |
|---|---|---|
| 오늘 방문자 수 | 오늘 체크인 또는 현장 접수한 방문자 수 | visits.checked_in_at 기준 |
| 현재 대기 인원 | 현재 WAITING 상태의 대기자 수 | queue_tickets.status = WAITING |
| 평균 대기시간 | 체크인/접수부터 호출까지 평균 시간 | called_at - issued_at |
| 노쇼율 | 예약 후 방문하지 않은 비율 | NO_SHOW / 전체 예약 |
| 시간대별 방문자 수 | 시간대별 방문 수 | checked_in_at의 hour 기준 |
| 업무별 평균 대기시간 | 업무 유형별 평균 대기시간 | service_type별 평균 |
| 예약/현장 방문 비율 | 예약 방문과 현장 접수 비율 | visit_type 기준 |
| 창구별 처리 건수 | 창구별 완료 처리 건수 | service_processes 기준 |

## 3. 직원용 지표

| 지표 | 설명 |
|---|---|
| 오늘 예약자 수 | 오늘 예약된 전체 인원 |
| 현재 대기 인원 | 직원이 처리해야 할 현재 대기자 수 |
| 호출 중 인원 | CALLED 상태 인원 |
| 처리 중 인원 | IN_PROGRESS 상태 인원 |
| 보류 인원 | HOLD 상태 인원 |
| 처리 완료 수 | 오늘 COMPLETED 처리 건수 |

## 4. 사용자용 혼잡도 지표

| 지표 | 설명 |
|---|---|
| 현재 대기 인원 | 업무 유형별 현재 대기 인원 |
| 예상 대기시간 | 현재 대기 인원과 평균 처리시간 기반 예상 |
| 혼잡도 | 여유, 보통, 혼잡 |
| 안내 문구 | 방문 권장 또는 혼잡 안내 메시지 |

## 5. 혼잡도 기준

| 혼잡도 | 대기 인원 기준 | 예상 대기시간 기준 | 표시 |
|---|---:|---:|---|
| LOW | 5명 이하 | 10분 이하 | 여유 |
| NORMAL | 6~15명 | 11~30분 | 보통 |
| HIGH | 16명 이상 | 31분 이상 | 혼잡 |

최종 혼잡도는 대기 인원 기준과 예상 대기시간 기준 중 더 높은 값을 사용합니다.

## 6. 주요 계산식

### 평균 대기시간

```text
평균 대기시간 = 평균(called_at - issued_at)
```

### 노쇼율

```text
노쇼율 = NO_SHOW 예약 수 / 전체 예약 수 * 100
```

취소된 예약은 노쇼율 계산에서 제외할 수 있습니다.

### 예약/현장 방문 비율

```text
예약 방문 비율 = visit_type = RESERVED 수 / 전체 visit 수 * 100
현장 방문 비율 = visit_type = WALK_IN 수 / 전체 visit 수 * 100
```

### 예상 대기시간

```text
예상 대기시간 = 현재 대기 인원 * 최근 평균 처리시간
```

## 7. 대시보드 화면 지표 구성

| 카드 | 표시값 |
|---|---|
| 오늘 방문자 수 | 120명 |
| 현재 대기 인원 | 18명 |
| 평균 대기시간 | 24분 |
| 노쇼율 | 8.5% |

## 8. 운영 개선 제안 예시

```text
최근 4주간 월요일 오전 10시~11시에 예방접종 방문자가 가장 많이 집중되었습니다.
해당 시간대 평균 대기시간은 42분으로 기준값 30분을 초과했습니다.
예방접종 창구를 1개 추가 배치하거나 해당 시간대 예약 가능 인원을 조정하는 것이 권장됩니다.
```

## 9. 데이터 집계 방식

| 단계 | 방식 |
|---|---|
| MVP | 실시간 쿼리 기반 집계 |
| 2차 | 일별/시간대별 배치 집계 테이블 도입 |

## 10. 지표별 데이터 소스

| 지표 | 주요 테이블 |
|---|---|
| 오늘 방문자 수 | visits |
| 현재 대기 인원 | queue_tickets |
| 평균 대기시간 | queue_tickets |
| 노쇼율 | reservations |
| 시간대별 방문자 수 | visits |
| 업무별 평균 대기시간 | service_types, queue_tickets |
| 예약/현장 방문 비율 | visits |
| 창구별 처리 건수 | service_windows, service_processes |
