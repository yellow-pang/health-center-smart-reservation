# 테스트 시나리오

## 1. 테스트 범위

| 구분 | 테스트 대상 |
|---|---|
| 인증 | 로그인, 토큰 재발급, 권한 검증 |
| 예약 | 예약 가능 시간 조회, 예약 신청, 예약 취소 |
| 방문 | 예약자 체크인, 현장 접수 |
| 대기 | 대기번호 발급, 호출, 처리 시작, 완료, 보류 |
| 관리자 | 업무 유형, 창구, 예약 슬롯 관리 |
| 대시보드 | 요약 지표, 혼잡도, 통계 조회 |

## 2. 인증 테스트

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| AUTH-TC-001 | 올바른 이메일과 비밀번호로 로그인 | Access Token과 Refresh Token 발급 |
| AUTH-TC-002 | 잘못된 비밀번호로 로그인 | 로그인 실패 오류 |
| AUTH-TC-003 | 만료된 Access Token으로 API 호출 | 인증 오류 |
| AUTH-TC-004 | Refresh Token으로 Access Token 재발급 | 새 Access Token 발급 |
| AUTH-TC-005 | 권한 없는 사용자가 관리자 API 호출 | 403 Forbidden |

## 3. 예약 테스트

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| RSV-TC-001 | 업무 유형 조회 | 예방접종, 건강검진/검사, 건강상담 목록 반환 |
| RSV-TC-002 | 예약 가능 시간 조회 | 선택 날짜의 예약 슬롯 목록 반환 |
| RSV-TC-003 | 예약 신청 | 예약 상태 RESERVED로 저장 |
| RSV-TC-004 | 예약 슬롯 정원 초과 예약 | RESERVATION_SLOT_FULL 오류 |
| RSV-TC-005 | 동일 사용자 동일 시간대 중복 예약 | RESERVATION_DUPLICATED 오류 |
| RSV-TC-006 | 내 예약 목록 조회 | 로그인 사용자 예약 목록 반환 |
| RSV-TC-007 | 방문 1시간 전 예약 취소 | 예약 상태 CANCELED 변경 |
| RSV-TC-008 | 방문 1시간 이내 예약 취소 | RESERVATION_CANCEL_TIME_EXPIRED 오류 |
| RSV-TC-009 | 지난 날짜 예약 신청 | INVALID_RESERVATION_DATE 오류 |
| RSV-TC-010 | 14일 이후 예약 신청 | INVALID_RESERVATION_DATE 오류 |

## 4. 방문 테스트

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| VISIT-TC-001 | 예약번호로 체크인 | Visit 생성, QueueTicket 생성 |
| VISIT-TC-002 | 존재하지 않는 예약번호 체크인 | RESERVATION_NOT_FOUND 오류 |
| VISIT-TC-003 | 이미 체크인한 예약 재체크인 | ALREADY_CHECKED_IN 오류 |
| VISIT-TC-004 | 현장 방문자 접수 | Visit 생성, QueueTicket 생성 |
| VISIT-TC-005 | 직원 대리 접수 | visit_type STAFF_PROXY로 저장 |
| VISIT-TC-006 | 예약 시간 10분 초과 방문 | 일반 대기열 이동 정책 적용 |

## 8. 통합 시나리오

### 예약 방문 정상 흐름

| 단계 | 행위 | 기대 결과 |
|---:|---|---|
| 1 | 사용자가 로그인 | 토큰 발급 |
| 2 | 업무 유형 조회 | 업무 목록 반환 |
| 3 | 예약 가능 시간 조회 | 슬롯 목록 반환 |
| 4 | 예약 신청 | 예약 완료 |
| 5 | 직원이 예약번호로 체크인 | 방문 생성, 대기번호 발급 |
| 6 | 직원이 대기자 호출 | 상태 CALLED |
| 7 | 직원이 처리 시작 | 상태 IN_PROGRESS |
| 8 | 직원이 처리 완료 | 상태 COMPLETED |
| 9 | 관리자가 대시보드 조회 | 방문자 수와 평균 대기시간 반영 |

### 현장 방문 정상 흐름

| 단계 | 행위 | 기대 결과 |
|---:|---|---|
| 1 | 현장 방문자가 보건소 방문 | 직원 접수 대기 |
| 2 | 직원이 현장 접수 등록 | Visit 생성 |
| 3 | 시스템이 대기번호 발급 | QueueTicket 생성 |
| 4 | 직원이 호출 | 상태 CALLED |
| 5 | 직원이 처리 완료 | 상태 COMPLETED |
| 6 | 대시보드 반영 | 현장 방문 비율 증가 |
