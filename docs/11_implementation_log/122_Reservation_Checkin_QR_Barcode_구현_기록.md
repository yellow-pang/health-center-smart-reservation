# 예약 체크인 QR/바코드 구현 기록

## 1. 작업 목표

- 시민 예약 완료 화면과 내 예약 화면에서 직원에게 보여줄 수 있는 체크인 QR/바코드를 표시한다.
- 직원 체크인 화면에서 시민이 제시한 QR/바코드가 예약번호 입력 흐름과 연결된다는 점을 명확히 한다.
- 실제 스캐너 장비 없이도 예약번호 기반 QR/바코드 표시와 수동 입력 검증이 가능하도록 한다.

## 6. 구현 결정

| 항목 | 결정 |
|---|---|
| QR payload | 예약번호 문자열 |
| 바코드 형식 | Code128 SVG |
| QR 생성 | `qrcode` 패키지의 `toDataURL` 사용 |
| 바코드 생성 | `jsbarcode` 패키지 사용 |
| 표시 위치 | 예약 완료, 내 예약, 직원 예약 검색 결과 |
| 직원 체크인 방식 | 스캐너가 예약번호 입력칸에 값을 입력하거나 직원이 수동 입력 |

예약번호를 payload로 사용한 이유는 현재 체크인 API가 `reservationNo`만 받기 때문이다.
따라서 별도 백엔드 변경 없이 QR/바코드를 스캔했을 때 기존 예약번호 직접 입력 흐름과 바로 이어질 수 있다.

## 8. 사용자 확인 방법

시민 예약 완료 화면:

```text
1. 시민 계정으로 로그인한다.
2. 예약 신청을 완료한다.
3. 완료 화면에서 QR, 바코드, 예약번호가 표시되는지 확인한다.
```

시민 내 예약 화면:

```text
1. /citizen/reservations 화면으로 이동한다.
2. 예정된 예약에서 체크인 코드 버튼을 누른다.
3. QR, 바코드, 예약번호가 펼쳐지는지 확인한다.
```

직원 체크인 화면:

```text
1. 직원 계정으로 /staff/check-in 화면에 접속한다.
2. 예약자를 검색한다.
3. 검색 결과에 예약자 제시 코드가 표시되는지 확인한다.
4. 예약번호 입력칸에 QR/바코드 스캔값 또는 예약번호를 붙여넣고 접수한다.
```

## 9. 추가 테스트 체크리스트

- [ ] Happy: 예약 완료 직후 체크인 코드가 표시된다.
- [ ] Happy: 내 예약 화면에서 예약별 체크인 코드를 열고 닫을 수 있다.
- [ ] Happy: 직원 검색 결과에서 예약번호와 동일한 QR/바코드가 표시된다.
- [ ] Edge: 예약 취소/지난 예약에는 체크인 코드 버튼이 표시되지 않는다.
- [ ] Edge: 긴 예약번호도 바코드 영역에서 가로 스크롤로 확인할 수 있다.
- [ ] Bad: QR 생성 실패 시 예약번호와 바코드는 계속 표시된다.
