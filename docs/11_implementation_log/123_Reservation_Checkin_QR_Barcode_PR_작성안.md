## PR 본문

## 개요

시민 예약 완료 화면과 내 예약 화면에 체크인 QR/바코드를 표시해 방문 당일 직원에게 빠르게 제시할 수 있게 했습니다.

직원 체크인 화면에는 QR/바코드 스캐너가 예약번호 입력칸에 값을 입력하는 흐름을 안내하고, 예약 검색 결과에서도 시민이 제시한 코드와 같은 예약번호 기반 코드를 확인할 수 있게 했습니다.

## 변경 내용

- 예약번호 기반 체크인 코드 공통 컴포넌트 추가
  - `qrcode` 기반 QR 이미지 생성
  - `jsbarcode` 기반 Code128 SVG 바코드 생성
  - 예약번호 텍스트 함께 표시
- 시민 예약 완료 화면 보강
  - 예약 완료 직후 QR/바코드 표시
- 시민 내 예약 화면 보강
  - 예정된 예약 카드에서 체크인 코드 토글 표시
- 직원 체크인 화면 보강
  - 예약 검색 결과에 예약자 제시 코드 표시
  - 예약번호 직접 입력 안내를 QR/바코드 스캔 흐름에 맞게 수정
- 문서 갱신
  - 구현 기록
  - 전체 체크리스트
  - 보류 정리 목록

## 추가 테스트 체크리스트

- [ ] Happy: 예약 완료 직후 체크인 코드가 표시된다.
