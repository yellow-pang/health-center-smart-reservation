## 개요

전화번호 입력 시 사용자가 하이픈을 직접 입력하지 않아도 되도록 프론트엔드 입력 UX를 개선했습니다.
백엔드로 전달되는 값은 기존처럼 `010-1234-5678` 형태를 유지해 API 계약과 DB 저장 형태는 변경하지 않았습니다.

## 변경 내용

- 전화번호 입력 정규화 유틸 추가
- 시민 예약 신청 휴대폰 번호 입력 자동 포맷 적용
- 직원 현장 접수 휴대폰 번호 입력 자동 포맷 적용
- 관리자 직원 연락처 입력 자동 포맷 적용
- 회원가입, 아이디 찾기, 비밀번호 찾기 보조 화면 휴대폰 번호 입력 자동 포맷 적용

## 추가 테스트 체크리스트

- [ ] Happy: `01012345678` 입력 시 `010-1234-5678`로 자동 표시된다.
- [ ] Happy: `010-1234-5678` 붙여넣기 시 같은 값으로 유지된다.
- [ ] Edge: 숫자 외 문자를 붙여넣어도 숫자만 남고 하이픈 형식으로 정리된다.
- [ ] Edge: 11자리를 초과해 입력해도 11자리까지만 반영된다.
- [ ] Bad: 너무 짧은 전화번호로 제출할 때 백엔드 검증 오류가 기존 방식대로 표시된다.
