# 후속작업 통합 정리

## 1. 문서 목적

이 문서는 `docs/11_implementation_log` 아래 구현 기록과 PR 작성안에 흩어진 후속 작업 제안을 모아, 다음 브랜치에서 고를 수 있는 후보로 정리한다.

`01_보류_정리_목록.md`가 보류/고도화 항목의 원장이라면, 이 문서는 최근 구현 로그를 다시 훑어 실제로 남은 기능, 정책 결정, 검증 부채를 빠르게 찾기 위한 색인이다.

## 2. 확인 기준

- 완료된 후속 제안은 새 작업으로 다시 열지 않고 `완료됨`으로 표시한다.
- PR 문서의 Happy/Edge/Bad 체크리스트는 기능 미완료가 아니라 런타임 검증 항목으로 분리한다.
- 서버 기동, Docker 실행, Swagger `Try it out`, 브라우저 확인, Jenkins 실행, k6 VM 부하 테스트는 사용자 직접 수행 항목으로 유지한다.
- eGovFrame Simple Backend Template, Maven, MyBatis, `egovframework.healthcenter` 패키지 기준은 유지한다.

## 3. 현재 git/코드 상태 요약

2026-05-27 현재 로컬 작업 트리는 깨끗하고, `dev`는 `origin/dev`와 같은 커밋을 가리킨다.

최신 커밋 기준:

- `bf1e058` `Merge pull request #66 from yellow-pang/feat/auto-close-pending-queue-batch`
- 자동 NO_SHOW 배치, 대기열 조회 성능 개선, 배포 후 상태 확인 가이드, 관측성 스택 보정이 이미 반영되어 있다.

코드 구조 확인 결과:

- 백엔드 보건소 도메인은 `backend/src/main/java/egovframework/healthcenter` 아래 `common`, `dashboard`, `member`, `office`, `queue`, `reservation`, `visit`로 구성되어 있다.
- MyBatis Mapper XML은 `backend/src/main/resources/egovframework/mapper/healthcenter` 하위 구조를 사용한다.
- 프론트엔드는 `frontend/app`, `frontend/src`, `frontend/components` 기반 Next.js 구조를 유지한다.
- 이번 정리는 문서-only 작업이므로 백엔드 도메인, DB schema, API 구현 코드는 변경하지 않는다.

- Jenkins Pipeline 실제 실행
- Prometheus/Grafana/Loki 브라우저 확인
- k6 VM 부하 테스트 재측정
- OAuth provider 실제 왕복 확인
- PR merge, dev/main 최신화, 브랜치 삭제 같은 Git 운영 항목

## 7. 이번 문서 작업의 범위

- 최신 `dev` 커밋 기준으로 구현 로그와 전체 체크리스트에서 미완 후속 후보를 다시 수집했다.
- 이미 완료된 항목은 완료 또는 일부 완료로 재분류했다.
- 새 기능 구현, DB 스키마 변경, API 변경, 프론트 화면 변경은 하지 않았다.
- 기존 보류 원장인 `01_보류_정리_목록.md`와 중복되는 항목은 원장 ID를 유지하고, 이 문서에서는 탐색용 색인으로 연결했다.
