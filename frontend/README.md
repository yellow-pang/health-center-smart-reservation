# Frontend

보건소 스마트 예약·대기 및 혼잡도 분석 시스템의 프론트엔드 프로젝트입니다.

## 예정 기술

- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- v0 기반 화면 초안
- Recharts

## 주요 화면

- 로그인
- 예약 신청
- 예약 내역
- 현재 혼잡도
- 직원 현장 접수
- 직원 대기열 관리
- 관리자 대시보드

## 현재 상태

v0로 생성한 MVP 화면 골격이 추가된 상태입니다.

- Next.js App Router 기반 라우트 구성
- mock data/mock service 기반 화면 흐름 구현
- 시민, 직원, 관리자 역할별 주요 화면 추가
- 실제 백엔드 API 연동은 후속 작업 예정
